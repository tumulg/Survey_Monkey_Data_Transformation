# **Survey Monkey Data Transformation**  

## **Project Overview**  
This project focuses on **cleaning and transforming raw survey data** exported from Survey Monkey. The dataset contained **duplicates, inconsistent formatting, and missing values**, which were handled using **Python (Pandas)** to prepare the data for further analysis.  

## **Key Features**  
- **Trimmed whitespace & standardized text formatting** (case sensitivity, extra spaces)  
- **Removed duplicate & near-duplicate responses** using fuzzy matching  
- **Converted messy survey responses into a structured format**  
- **Prepared the cleaned dataset for relational databases & analysis**  

## **Project Files**  
| File Name | Description |
|-----------|------------|
| **Data - Survey Monkey Output.xlsx** | Raw, unprocessed survey data |
| **Data - Survey Monkey Output Edited.xlsx** | Contains the question and format sheet |
| **Final_Output.xlsx** | Fully transformed and cleaned dataset |
| **Script1 - Data_Manipulation.ipynb** | Jupyter Notebook with data cleaning logic |
| **Screenshots/** | Visual proof of transformations |

## **Technologies Used**  
- **Python** (Pandas, NumPy)  
- **Jupyter Notebook**  
- **Excel** for input/output verification
